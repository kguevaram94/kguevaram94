## 🧭 Engineering Principles | Principios de ingeniería

- **Automation first / Automatizar primero:** eliminate repetitive tasks and improve productivity.
- **Code quality / Calidad del código:** prioritize readability, testing and maintainability.
- **Security by design / Seguridad desde el diseño:** protect credentials and minimize permissions.
- **Human oversight / Supervisión humana:** keep approval gates for critical changes.
- **Continuous learning / Aprendizaje continuo:** experiment, measure and improve.
